Chordify

Python

Turns any YouTube video into a chord chart with the lyrics aligned underneath. CQT/CENS chroma with bass-aware Viterbi decoding, optional Demucs stem separation, and lyric transcription through Whisper or Parakeet. Runs fully offline, no API keys.

It started from a real problem: the songs my kid wanted to sing weren't on any chord site. The detector is scored against a synthetic ground-truth suite — 0.98 mean frame accuracy.
